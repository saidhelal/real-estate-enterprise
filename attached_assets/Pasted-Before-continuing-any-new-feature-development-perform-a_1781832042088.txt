FORM UX

Improve every form in the ERP.

Required fields:
- Display a clear red (*) beside every required field.

Optional fields:
- Display "(Optional)" in English.
- Display "(اختياري)" in Arabic.

Users must immediately know which fields are required.

Validation:
- Required fields must prevent saving if empty.
- Show clear validation messages.
- Focus automatically on the first invalid field.
- Highlight invalid fields with a red border.
- Optional fields must never block saving.
