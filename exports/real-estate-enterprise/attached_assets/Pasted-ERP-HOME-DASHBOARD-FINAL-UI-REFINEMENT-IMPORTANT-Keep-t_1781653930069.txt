VISUAL DESIGN
====================================================

1. Change all module cards to a lighter premium navy blue.

Current color is too dark.

Use a luxury enterprise navy color that is:
- 3 to 4 shades lighter than current
- Close to black
- Modern corporate style
- Consistent across all cards

2. Card Layout

Desktop:
- 4 cards per row

Tablet:
- 2 cards per row

Mobile:
- 1 card per row

3. Increase card size

- Wider cards
- Taller cards
- More internal spacing
- More spacing between cards

4. Typography

Main Module Title:
- Font Size: 24px to 28px
- Font Weight: 800
- White
- Center aligned

Sub Modules:
- Font Size: 16px to 18px
- Font Weight: 700
- Light gray
- Clear spacing
- Easy to read

5. Uniform Cards

All cards must have:
- Same width
- Same height
- Same spacing
- Same alignment

Even if one card contains more items.

6. Hover Effect

Add professional hover effects:

- Slight scale effect
- Soft shadow
- Smooth transition

No bright colors.
