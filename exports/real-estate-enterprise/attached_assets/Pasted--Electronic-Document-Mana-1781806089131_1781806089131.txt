أنشئ موديول رئيسي جديد باسم:

"إدارة الأرشيف الإلكتروني وإدارة المستندات (Electronic Document Management System - EDMS)"

ويكون هذا هو المستودع الرسمي الوحيد لجميع مستندات الشركة، ويرتبط بجميع موديولات النظام الحالية والمستقبلية.

المطلوب:

1- شاشة رئيسية تعرض:
- إجمالي المستندات.
- المستندات النشطة.
- المستندات المؤرشفة.
- المستندات المنتهية.
- المستندات قيد الاعتماد.
- آخر المستندات المضافة.

2- تقسيم المستندات حسب الموديول:
- العملاء.
- المشروعات.
- الوحدات.
- الحجوزات.
- العقود.
- الأقساط والتحصيل.
- الحسابات.
- الخزينة والبنوك.
- المشتريات.
- المخازن.
- المقاولون.
- الهندسة.
- الموارد البشرية.
- التأمينات.
- خدمة العملاء.
- الإدارة العامة.
- الشؤون القانونية.
- الأصول الثابتة.
- بنك الأراضي.
- أي موديول جديد مستقبلاً.

3- لكل مستند يتم حفظ:
- رقم المستند.
- اسم المستند.
- نوع المستند.
- الموديول التابع له.
- رقم السجل المرتبط.
- المشروع.
- العميل.
- الوحدة.
- القسم.
- تاريخ الإنشاء.
- تاريخ الانتهاء (إن وجد).
- الإصدار.
- حالة المستند.
- المستخدم الذي أضافه.
- آخر مستخدم قام بالتعديل.

4- يدعم رفع:
PDF
Word
Excel
PowerPoint
صور
DWG
DXF
ZIP
RAR
أي نوع ملفات آخر.

5- دعم تعدد الإصدارات (Version Control):
- حفظ جميع الإصدارات.
- الرجوع لأي إصدار سابق.
- مقارنة الإصدارات.
- عدم حذف أي إصدار نهائياً.

6- ربط المستندات تلقائياً بالسجل الخاص بها داخل كل موديول، بحيث تظهر داخل شاشة العميل أو المشروع أو العقد أو الوحدة دون تكرار البيانات.

7- البحث المتقدم بواسطة:
- رقم المستند.
- اسم المستند.
- العميل.
- المشروع.
- الوحدة.
- القسم.
- نوع الملف.
- المستخدم.
- التاريخ.
- الكلمات المفتاحية.

8- تصنيفات المستندات:
- عقود.
- مكاتبات.
- رسومات هندسية.
- تراخيص.
- مستندات قانونية.
- مستندات مالية.
- مستندات تأمينات.
- صور.
- محاضر اجتماعات.
- أي تصنيف يضاف مستقبلاً.

9- دورة حياة المستند:
مسودة → للمراجعة → معتمد → نشط → مؤرشف → منتهي.

10- Workflow للموافقات:
الموظف → مدير الإدارة → المدير العام → Owner / Super Admin حسب نوع المستند.

11- صلاحيات دقيقة:
- كل مستخدم يرى مستندات صلاحياته فقط.
- مدير الإدارة يرى مستندات إدارته.
- المدير العام يرى جميع الإدارات.
- Owner وSuper Admin لهما صلاحية كاملة.

12- منع الحذف النهائي (Hard Delete).
يسمح فقط بالأرشفة أو التعطيل.
أي حذف يحتاج موافقة Owner أو Super Admin فقط.

13- تسجيل جميع العمليات داخل Audit Trail:
رفع.
تعديل.
اعتماد.
رفض.
تحميل.
طباعة.
مشاركة.
أرشفة.
استرجاع.

14- دعم QR Code وBarcode لكل مستند.

15- دعم التوقيع الإلكتروني والختم الإلكتروني.

16- إمكانية ربط أكثر من مستند بنفس العميل أو المشروع أو العقد أو الوحدة.

17- إنشاء تنبيهات تلقائية عند:
- قرب انتهاء مستند.
- انتهاء مستند.
- طلب اعتماد.
- رفض اعتماد.
- إضافة إصدار جديد.

18- دعم السحب والإفلات (Drag & Drop).

19- دعم المعاينة المباشرة داخل النظام دون تنزيل الملف.

20- دعم التخزين السحابي مع إمكانية نقل الملفات مستقبلاً إلى أي مزود تخزين دون تعديل النظام.

21- يجب أن يكون الموديول مرتبطاً بالكامل مع موديول الإشعارات، وإدارة المتابعة والرقابة التنفيذية، والصلاحيات، والطباعة، وسجل المراجعة (Audit Trail)، مع عدم تكرار أي بيانات أو إنشاء بيانات مكررة داخل النظام.
